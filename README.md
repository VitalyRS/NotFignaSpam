# 🤖 NotFignaSpam — Anti-Spam Telegram Bot

Telegram-бот для защиты чатов от спама с машинным обучением, системой карантина и автоматической модерацией.

## ✨ Возможности

### 🛡️ Система карантина
- **7-дневный карантин** для новых пользователей
- Автоматическое отслеживание всех новых участников
- **Ранний выход из карантина** — после 2 "чистых" сообщений пользователь получает полные права
- Принудительное управление карантином через команды

### 🔍 Автоматические проверки
| Проверка | Действие | Причина в БД |
|----------|----------|---------------|
| ML-модель спама | Блокировка + удаление | `ML-спам детектор` |
| 3 одинаковых сообщения | Блокировка + удаление всех повторов | `Повтор сообщений` |
| 3 медиа подряд | Блокировка + удаление всех медиа | `3 медиа подряд` |
| Ссылки/entities от новых | Блокировка + удаление | `Entities (ссылки/форматирование)` |
| Упоминание USDT/USDC | Блокировка + удаление | `USDT/USDC` |
| Нелатинские/некириллические символы (>5) | Блокировка + удаление | `Спецсимволы (не лат/кир)` |
| Медиа от новых пользователей | Удаление (до 3-го) | — |
| Плохой никнейм/имя | Автоматический бан | — |

### 📊 ML-классификатор спама
- TF-IDF векторизация текста
- Обученная модель (`modelSPAM.joblib`)
- Нормализация текста с учётом кириллицы

## 📋 Команды бота

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку по всем командам |
| `/strange` | Список пользователей на карантине |
| `/addc <user_id>` | Убрать пользователя из карантина, дать полные права |
| `/restrict <id1,id2,...>` | Ограничить права пользователям |
| `/change <текст>` | Изменить сообщение при выходе из карантина |
| `/suka <никнейм>` | Добавить никнейм в чёрный список |
| `/list` | Показать чёрный список никнеймов |

> ⚠️ Все команды доступны только администратору (MASTER_ID)

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- PostgreSQL (или Neon.tech)

### 1. Клонирование
```bash
git clone https://github.com/VitalyRS/NotFignaSpam.git
cd NotFignaSpam
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Переменные окружения
Создайте файл `.env` или установите переменные:

```env
TELEGRAM_BOT_TOKEN=your_bot_token
MASTER_ID=your_telegram_user_id
TARGET_CHAT_ID=your_chat_id
DSN=postgresql://user:pass@host/db?sslmode=require
WEBHOOK_URL=https://your-app.railway.app  # опционально
```

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `MASTER_ID` | Ваш Telegram ID (админ) |
| `TARGET_CHAT_ID` | ID чата для модерации |
| `DSN` | Строка подключения PostgreSQL |
| `WEBHOOK_URL` | URL для вебхука (опционально) |

### 4. Запуск
```bash
python bot.py
```

## 🗄️ База данных

Бот автоматически создаёт таблицы при первом запуске:

### Таблица `users`
```sql
CREATE TABLE users (
    user_id BIGINT PRIMARY KEY,
    username TEXT,
    user_handle TEXT,
    join_time TIMESTAMPTZ,
    notified BOOLEAN,
    status TEXT,
    text JSONB,
    text_id JSONB,
    restrict_reason TEXT  -- Причина блокировки
);
```

### Таблица `bad_words`
```sql
CREATE TABLE bad_words (
    word TEXT PRIMARY KEY
);
```

### Таблица `settings`
```sql
CREATE TABLE settings (
    key TEXT PRIMARY KEY,
    value TEXT
);
```

Используется для хранения настроек бота, например:
- `quarantine_exit_msg` — сообщение при выходе пользователя из карантина

## 📈 Логика работы

```
Новый пользователь заходит в чат
            ↓
    Добавляется в карантин (7 дней)
            ↓
    ┌───────────────────────────────────┐
    │     Проверка каждого сообщения    │
    │  ┌─────────────────────────────┐  │
    │  │ ✗ Спам (ML)                 │──┼──→ Блокировка
    │  │ ✗ Повторы (3 раза)          │──┼──→ Блокировка
    │  │ ✗ 3 медиа подряд            │──┼──→ Блокировка
    │  │ ✗ Ссылки/entities           │──┼──→ Блокировка
    │  │ ✗ USDT/USDC                 │──┼──→ Блокировка
    │  │ ✗ Медиа (до 3-го)           │──┼──→ Удаление
    │  │ ✓ Чистое сообщение          │──┼──→ clean_count++
    │  └─────────────────────────────┘  │
    └───────────────────────────────────┘
            ↓
    clean_count >= 2?
        ↓ Да
    ✅ Полные права, выход из карантина
    📨 Reply: "Вы вышли с карантина, вам даны полные права"
```

## 🔧 Настройка

### Изменение срока карантина
В классе `UserManager`:
```python
QUARANTINE_SECONDS = 7 * 24 * 60 * 60  # 7 дней
```

### Количество чистых сообщений для промоута
В методе `handle_message`:
```python
if clean_count >= 2:  # Изменить на нужное число
```

### Изменение сообщения при выходе из карантина
Отправьте боту команду:
```
/change Ваш новый текст сообщения
```

По умолчанию: `"Вы вышли с карантина, вам даны полные права"`
