# 🤖 Anti-Spam Telegram Bot

Мощный Telegram-бот для защиты чатов от спама с машинным обучением, системой карантина, автоматической модерацией и уникальными правилами для подгрупп (топиков).

## ✨ Возможности

### 🛡️ Система карантина
- **7-дневный карантин** для новых пользователей
- Автоматическое отслеживание всех новых участников
- **Ранний выход из карантина** — после 2 "чистых" сообщений пользователь получает полные права
- Принудительное управление карантином через команды 

### 🗂️ Модерация по подгруппам (Топикам)
Бот поддерживает гибкую настройку правил в зависимости от темы форума:
- **Новости и Налоги (`news`)**: Раздел только для чтения (обсуждения переносятся в болталку).
- **Посылки, Подвезу (`parcels`)**: Удаление, если нет тегов `#ищу`, `#передам`, `#возьму`, `#еду`, `#куда` или `#из`. Запрет на "кружочки" и голосовые сообщения. Лимит: 1 публикация от пользователя в 3 дня (72 часа).
- **Работа, Услуги, Жилье (`ads`)**: Удаление, если нет тегов `#услуги`, `#работа` или `#квартира`. Лимит: 1 публикация от пользователя в 24 часа.
- **ВНЖ/Гражданство (`visa`)**, **SOS (`sos`)** и **Обратная связь (`feedback`)**: Бот удаляет все видео, "кружочки" и голосовые сообщения.
- **Остальные топики (`life`, `spanish`, `tourism`, `family`, `dating`, `chat`)**: Действуют только стандартные правила антиспама, без дополнительных ограничений.

> **💡 Альбомы с медиа**: При отправке альбома фотографий в топиках `ads` и `parcels` бот проверяет обязательный тег только у первого фото (с текстом). Остальные фотографии из одного альбома пропускаются автоматически, чтобы не портить публикацию.
> **💡 Мягкие предупреждения**: Если пользователь забыл указать обязательный тег или нарушил лимит времени (флуд-контроль) в разделах `parcels` или `ads`, бот не только удалит его сообщение, но и отправит в ответ временное уведомление (исчезнет через 30 секунд), информируя о причине удаления.

### 🔍 Автоматические проверки в карантине
| Проверка | Действие |
|----------|----------|
| ML-модель спама | Блокировка + удаление |
| 3 одинаковых сообщения | Блокировка + удаление всех повторов |
| 3 медиа подряд | Блокировка + удаление всех медиа |
| Ссылки/Пересылки (Forwards) | Блокировка + удаление |
| Упоминание USDT/USDC | Блокировка + удаление |
| Нелатинские/некириллические символы (>5) | Блокировка + удаление |
| Медиа от новых пользователей | Общее удаление (Но **игнорируется** в топиках `ads` и `parcels`, если сообщение содержит правильный тег) |
| Плохой никнейм/имя | Бан при входе |

> **🚀 Inline-Кнопки Восстановления**: При каждой автоматической блокировке пользователя (спам, ссылки, повторы), администратор получает уведомление (с указанием топика) и встроенной кнопкой **"✅ Восстановить (Не спам)"**. Нажатие на кнопку мгновенно снимает ограничения с пользователя.

### 📊 Web Dashboard
Встроенная веб-панель доступна на порту `:8080`.
- **`<IP>:8080/`** (Основной вид): Просмотр пользователей на карантине, заблокированных юзеров, их последних сообщений и причин блокировки.
- **`<IP>:8080/limits`** (Дашборд Лимитов): Просмотр активных таймеров (флуд-контроля) для всех пользователей, публикующих в топиках `ads` (24 часа) и `parcels` (72 часа), а также оставшегося времени ограничения.

### 📨 Логирование и пересылка сторонней активности (Нецелевые чаты)
Бот настроен на строгую изоляцию целевого чата. Вся активность за его пределами пересылается в специальный лог-чат:
- **Защита только целевого чата**: Все правила карантина, проверки на спам, лимиты по времени и ограничения топиков действуют **исключительно** внутри целевого чата (`TARGET_CHAT_ID`).
- **Пересылка из других чатов**: Если бот добавлен в сторонние группы/каналы или получает личные сообщения от посторонних пользователей (не администраторов), любые новые входящие сообщения автоматически форвардятся в специальный лог-чат (`-5180070081`).
- **Поддержка контента**: Корректно пересылаются все типы сообщений — обычный текст, анонимные публикации от лица каналов, а также любые медиафайлы (фотографии, видео, аудио, голосовые сообщения, видеокружочки, файлы и стикеры).
- **Сохранение контекста ответов**: Если пересылаемое сообщение являлось ответом (reply), бот парсит имя и юзернейм автора исходной реплики, её текст и добавляет к лог-плашке контекст ответа (`📎 Отвечал на: ...`).
- **Информационный лог**: Вместе с сообщением в лог-чат отправляется детальная карточка со сведениями о чате-источнике (название, ID, ссылка), имени/ID автора и типе публикации.

## 📋 Команды администратора

### Управление карантином и подгруппами
| Команда | Описание |
|---------|----------|
| `/set_topic <тип>` | **Важно!** Команду нужно отправить прямо внутрь нужной подгруппы (топика), чтобы бот понял, какие правила к ней применять. (Типы: `news`, `visa`, `sos`, `parcels`, `ads`, `feedback`, `life`, `spanish`, `tourism`, `family`, `dating`, `chat`) |
| `/strange` | Список новых пользователей на карантине |
| `/addc <user_id>` | Досрочно убрать пользователя из карантина и дать права |
| `/restrict <id1,...>` | Принудительно заблокировать права пользователям |
| `/change <текст>` | Изменить сообщение при успешном выходе из карантина |
| `/reset_limit <id> <топик>` | Полностью сбросить таймер "чистого времени" (флуд-лимит) пользователя в топике. (например: `/reset_limit 1234 ads`) |
| `/nolim <user_id>` | Полностью снять флуд-контроль (лимиты времени) пользователя сразу во всех специфичных топиках (`ads` и `parcels`) |
| `/send <ID_чата> <текст>` | Отправить произвольное сообщение от имени бота в указанный чат |
| `/chatinfo <ID_чата>` | Показать информацию о чате и правах бота в нём |

### Чёрный список имён
| Команда | Описание |
|---------|----------|
| `/suka <никнейм>` | Добавить никнейм в чёрный список (блокирует при входе) |
| `/sukan <никнейм>` | Удалить никнейм из чёрного списка |
| `/list` | Показать весь чёрный список |

> ⚠️ Все команды доступны только администратору (`MASTER_ID`)

**Как работает команда `/set_topic`?**
Когда у вас группа с темами (Форум), каждый топик имеет свой уникальный ID (`message_thread_id`). Чтобы бот знал, что конкретная ветка — это, например, "Посылки", вам нужно зайти в нее с телефона или компьютера и прямо туда отправить сообщение `/set_topic parcels`. После этого бот запомнит ID этого топика в базе данных и начнет применять нужные алгоритмы именно к сообщениям из этой ветки. Эту операцию нужно проделать один раз для каждого топика площадки.

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- PostgreSQL

### 1. Переменные окружения (.env)
Создайте `.env` файл в корне проекта:
```env
TELEGRAM_BOT_TOKEN=your_bot_token
MASTER_ID=your_telegram_user_id
TARGET_CHAT_ID=your_chat_id
DSN=postgresql://user:pass@host/db?sslmode=require
WEBHOOK_URL=https://your-app.com  # опционально
PORT=8080 # Внутренний порт веб-сервера
```

### 2. Запуск локально
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 🗄️ База данных

Бот использует PostgreSQL (через асинхронный драйвер `asyncpg`). Таблицы создаются **автоматически** при первом запуске:
- `users`: Статусы пользователей, история сообщений, таймеры.
- `bad_words`: Список запрещенных никнеймов.
- `settings`: Настройки (кастомное сообщение при выходе) и привязки топиков.
- `topic_limits`: История последних сообщений пользователей по каждому топику для работы флуд-контроля.

## 📈 Логика работы карантина
1. Новый пользователь вступает в `TARGET_CHAT_ID`
2. Заносится в БД на карантин (по умолчанию 7 дней)
3. При каждом сообщении:
   - Сначала проверяется `check_topic_rules()` (лимиты времени для объявлений, обязательные теги, запрет медиа в топиках).
   - Если прошло — проверяется глобальный антиспам "на лету" (Ссылки, USDT, ML модель, повторы).
   - Если чистое — `clean_count` увеличивается.
4. Когда `clean_count == 2`, бот дает полные права, отправляет приветственное сообщение и удаляет из карантина.
