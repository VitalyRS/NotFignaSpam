# 🤖 Anti-Spam Telegram Bot («Дядя Стёпа»)

Мощный Telegram-бот для защиты чатов от спама с машинным обучением, системой карантина, автоматической модерацией и уникальными правилами для подгрупп (топиков).

---

## ✨ Возможности

### 🛡️ Система карантина
- **7-дневный карантин** для новых пользователей.
- Автоматическое отслеживание всех новых участников целевого чата (без лишнего спам-уведомления администратору о каждом входе).
- **Ранний выход из карантина** — после 2 разных осмысленных ("чистых") сообщений пользователь автоматически получает полные права (без публикации лишних служебных сообщений в общий чат).
- **Предупреждения Дяди Стёпы**: при попытке отправить медиа, ссылки, спецсимволы или спам на карантине, бот удаляет сообщение и отправляет в чат предупреждение от имени Дяди Стёпы с таймером **автоудаления через 30 секунд**.
- Принудительное управление карантином через команды администратора.

### 🔓 Белый список без ограничений (`/no_filter`)
- Возможность добавлять доверенных пользователей или Telegram-каналы (по числовому ID или по `@username`).
- Пользователи и каналы из белого списка **полностью освобождаются** от:
  - Карантина и спам-фильтра;
  - Обязательных тегов в топиках (`#услуги`, `#работа`, `#квартира`, `#ищу` и др.);
  - Ограничений флуд-контроля по времени (24ч / 72ч);
  - Запретов на медиа, кружочки, голосовые сообщения и ссылки.

### 🗂️ Модерация по подгруппам (Топикам)
Бот поддерживает гибкую настройку правил в зависимости от темы форума:
- **Новости и Налоги (`news`)**: Раздел только для чтения (обсуждения переносятся в болталку).
- **Посылки, Подвезу (`parcels`)**: Удаление, если нет тегов `#ищу`, `#передам`, `#возьму`, `#еду`, `#куда` или `#из`. Запрет на "кружочки" и голосовые сообщения. Лимит: 1 публикация от пользователя в 3 дня (72 часа).
- **Работа, Услуги, Жилье (`ads`)**: Удаление, если нет тегов `#услуги`, `#работа` или `#квартира`. Лимит: 1 публикация от пользователя в 24 часа.
- **ВНЖ/Гражданство (`visa`)**, **SOS (`sos`)** и **Обратная связь (`feedback`)**: Бот удаляет все видео, "кружочки" и голосовые сообщения.
- **Остальные топики (`life`, `spanish`, `tourism`, `family`, `dating`, `chat`)**: Действуют только стандартные правила антиспама, без дополнительных ограничений.

> **💡 Альбомы с медиа**: При отправке альбома фотографий в топиках `ads` и `parcels` бот проверяет обязательный тег только у первого фото (с текстом). Остальные фотографии из одного альбома пропускаются автоматически.  
> **💡 Мягкие предупреждения**: Если пользователь забыл указать обязательный тег или нарушил лимит времени (флуд-контроль) в разделах `parcels` или `ads`, бот удалит его сообщение и отправит в ответ временное уведомление (исчезает через 30 секунд).

### 🔍 Автоматические проверки в карантине
| Проверка | Действие |
|----------|----------|
| ML-модель спама | Блокировка + удаление + предупреждение Дяди Стёпы (30 сек) |
| 3 одинаковых сообщения | Блокировка + удаление всех повторов + предупреждение (30 сек) |
| 3 медиа подряд | Блокировка + удаление всех медиа |
| Ссылки / Link Preview / Forwards | Блокировка + удаление + предупреждение (30 сек) |
| Упоминание USDT/USDC | Блокировка + удаление + предупреждение (30 сек) |
| Нелатинские/некириллические символы (>5) | Блокировка + удаление + предупреждение (30 сек) |
| Медиа от новых пользователей | Удаление + предупреждение Дяди Стёпы (30 сек) |
| Плохой никнейм/имя | Бан при входе |

> **🚀 Inline-Кнопки Разблокировки и Снятия с Карантина**: При каждой автоматической блокировке пользователя (спам, ссылки, 3 медиа подряд, повторы) администратор получает отчёт в личный чат с инлайн-кнопкой **"✅ Разблокировать и снять с карантина"**. Нажатие мгновенно возвращает все права и удаляет пользователя из базы карантина.

### 📊 Web Dashboard
Встроенная веб-панель доступна на порту `:8080`.
- **`<IP>:8080/`** (Основной вид): Просмотр пользователей на карантине, заблокированных юзеров, их последних сообщений и причин блокировки.
- **`<IP>:8080/limits`** (Дашборд Лимитов): Просмотр активных таймеров (флуд-контроля) для всех пользователей, публикующих в топиках `ads` (24 часа) и `parcels` (72 часа).

---

### 📨 Логирование и пересылка сторонней активности (Нецелевые чаты)
- **Защита только целевого чата**: Все правила карантина, проверки на спам и лимиты действуют **исключительно** внутри целевого чата (`TARGET_CHAT_ID`).
- **Пересылка из других чатов**: Если бот добавлен в сторонние группы/каналы или получает личные сообщения, входящие сообщения автоматически форвардятся в специальный лог-чат (`-5180070081`).
- **Сохранение контекста ответов**: Если пересылаемое сообщение являлось ответом (reply), бот парсит имя и юзернейм автора исходной реплики, её текст и добавляет контекст (`📎 Отвечал на: ...`).

## 📋 Команды администратора

### Управление карантином и подгруппами
| Команда | Описание |
|---------|----------|
| `/set_topic <тип>` | Привязать правила к топику (отправлять прямо в ветку топика) |
| `/strange` | Список новых пользователей на карантине |
| `/addc <user_id>` | Досрочно убрать пользователя из карантина и дать полные права |
| `/restrict <id1,id2,...>` | Принудительно заблокировать права пользователям |
| `/change <текст>` | Изменить текст сообщения при выходе из карантина |
| `/reset_limit <id> <топик>` | Сбросить таймер флуд-лимита пользователя в конкретном топике |
| `/nolim <user_id>` | Снять флуд-контроль пользователя сразу в `ads` и `parcels` |
| `/send <ID_чата> <текст>` | Отправить сообщение от имени бота в указанный чат |
| `/chatinfo <ID_чата>` | Показать права и статус бота в указанном чате |

### Белый список без ограничений
| Команда | Описание |
|---------|----------|
| `/no_filter <ID/@username>` | Добавить пользователя или канал в белый список (без спам-фильтра, тегов и лимитов) |
| `/no_filter_del <ID/@username>` | Удалить пользователя или канал из белого списка |
| `/no_filter_list` | Показать список всех добавленных пользователей и каналов |

### Чёрный список никнеймов
| Команда | Описание |
|---------|----------|
| `/suka <никнейм>` | Добавить никнейм в чёрный список (бан при входе) |
| `/sukan <никнейм>` | Удалить никнейм из чёрного списка |
| `/list` | Показать весь чёрный список |

> ⚠️ Все команды доступны только администратору (`MASTER_ID`).

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- PostgreSQL

### 1. Переменные окружения (.env)
Создайте `.env` файл в корне проекта:
```env
TELEGRAM_BOT_TOKEN=your_bot_token
MASTER_ID=your_telegram_user_id
TARGET_CHAT_ID=your_chat_id
DSN=postgresql://user:pass@host/db?sslmode=require
WEBHOOK_URL=https://your-app.com  # опционально
PORT=8080 # Внутренний порт веб-сервера
```

### 2. Запуск локально
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 🗄️ База данных

Бот использует PostgreSQL (`asyncpg`). Таблицы создаются **автоматически**:
- `users`: Статусы пользователей на карантине, история сообщений, счётчики чистых сообщений.
- `bad_words`: Чёрный список никнеймов.
- `settings`: Настройки бота и привязки топиков.
- `topic_limits`: История таймеров флуд-контроля по топикам (`ads`, `parcels`).
- `no_filter_users`: Белый список пользователей и каналов без ограничений.
